## Where to Add New Code

**New Feature:**
- Primary code: Add new component functions inside the `<script type="text/babel">` block before App definition
- Event handlers: Add new state variables and handlers inside App component using useState
- Rendering: Add new JSX sections or child components within App's return statement
- Tests: Not applicable - create test file if testing framework is added

**New Visual Diagram:**
- Implementation: Create new component following pattern of VBitDiagram, ChiploadDiagram, PassDepthDiagram (receives parameters as props, returns SVG)
- Location: Define above App component in script tag
- Integration: Add tab for new diagram in activeTab conditional rendering; add tab button in tabs section

**New Tool or Material:**
- Tool addition: Add object to TOOLS array with `dia`, `label`, `group` properties; add chipload range in `buildChiploads()` function's if/else chain for the new diameter bracket
- Material addition: Add object to materials array with `name`, `color`, `chipload` properties; chipload generated via `buildChiploads()` with appropriate scale factor

**New Calculation Rule or Formula:**
- Add to `<div className="card">` with `<div className="rule">` class in Rules of Thumb section, or to formula displays in diagram tabs

**Styling Adjustments:**
- Global styles: Modify `<style>` tag in head (CSS variables not used; hardcoded hex colors)
- Component-specific styles: Use inline style objects in JSX (object format with camelCase properties)
- Dynamic styles: Use conditional ternary or object spread in style prop (example: `style={matIdx===i ? {borderColor:m.color,color:m.color,background:...} : {}}`)
